\# Калькулятор с плагинами (C++)



\## Структура проекта

\- `calc` — главное приложение (.exe) с парсером математических выражений.

\- `sin\_plugin` — плагин для вычисления синуса.

\- `ln\_plugin` — плагин для вычисления логарифма.

\- `cos\_plugin` — плагин для вычисления косинуса.





\## Как собрать

1\. Откройте файл `calc.sln` в Visual Studio.

2. Нажмите \*\*Сборка -> Собрать решение\*\* (Build -> Build Solution).

3. Готовый `calc.exe` и папка `plugins` с DLL появятся в папке `bin/`.



\## Как запустить

Запустите `calc.exe` из командной строки или проводника.
