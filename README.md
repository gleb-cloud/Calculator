# Калькулятор с плагинами (C++)

## Структура проекта
- `calc` — главное приложение (.exe) с парсером математических выражений.
- `sin_plugin` — плагин для вычисления синуса.
- `ln_plugin` — плагин для вычисления логарифма.
- `cos_plugin` — плагин для вычисления косинуса.
- `include` — общий заголовочный файл `plugin_interface.h`.

## Как собрать
1. Откройте файл `Calculator.sln` в Visual Studio.
2. Выберите конфигурацию (например, `Release` или `Debug`).
3. Нажмите **Сборка -> Собрать решение** (Build -> Build Solution).
4. Готовый `calc.exe` и папка `plugins` с DLL появятся в папке `bin/`.

## Как запустить
Запустите `calc.exe` из командной строки или проводника.
Примеры ввода:
- `16 + 4 * (3 - 1)`
- `sin(90) + cos(0)`
- `ln(-10)` (вызовет ошибку, но программа не упадет)
